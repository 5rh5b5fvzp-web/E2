5. 启动。

## 七、常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 登录 500，`Access denied ... (using password: NO)` | 没读到 `jdbc-local.properties` | 确认文件存在且口令正确，重新打包/重启 |
| 所有接口 401 | 没登录或 Cookie 没带 | 先调登录；ApiFox 开启 Cookie |
| 404 | context path 不是 `/E2` | Deployment 里把 Application context 设为 `/E2` |
| `Invalid bound statement` | 用了原生 `SqlSessionFactoryBean` | 必须用 `MybatisSqlSessionFactoryBean`（已配置） |
| 分页不生效 | 没注册分页插件 | `SpringConfig` 已用 Java API 注册 |
| 页面 404 | JSP 在 `WEB-INF/views` 下 | 通过 `/students`、`/scores` 访问 |
| 8080 被占用 | 旧 Tomcat 还在跑 | 停掉旧实例或改端口 |

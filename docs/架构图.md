# E2 项目架构图

## 1. 分层架构

```text
┌──────────────────────────────────────────────────────────────┐
│                        浏览器 / ApiFox                        │
│              HTML + 原生 JS（fetch） / HTTP JSON              │
└──────────────────────────────┬───────────────────────────────┘
                               │ HTTP :8080/E2
┌──────────────────────────────▼───────────────────────────────┐
│ Tomcat 10.1（Jakarta Servlet 6）                             │
│  └─ CharacterEncodingFilter（UTF-8）                         │
│  └─ DispatcherServlet（映射 "/"）                            │
│       └─ LoginInterceptor（登录拦截，未登录 401 / 跳登录页）   │
│       └─ RoleInterceptor（角色校验：ADMIN / TEACHER / STUDENT）│
└──────────────────────────────┬───────────────────────────────┘
                               │
┌──────────────────────────────▼───────────────────────────────┐
│ 表现层 Controller（SpringMVC 子容器）                          │
│  AuthController / StudentController / ScoreController        │
│  MetaController / PageController / DevController             │
│  ├─ @Valid + BindingResult（JSR303 参数校验）                 │
│  ├─ WebLogAspect（AOP 环绕：入参 / 耗时 / 异常）              │
│  └─ GlobalExceptionHandler（统一异常 → Result）               │
└──────────────────────────────┬───────────────────────────────┘
                               │ 调用接口
┌──────────────────────────────▼───────────────────────────────┐
│ 业务层 Service（Spring 根容器）                                │
│  StudentService / ScoreService / ClassService / CourseService │
│  AuthService（接口 + Impl）                                   │
│  ├─ IService / ServiceImpl（MyBatis-Plus 通用 CRUD）          │
│  ├─ LambdaQueryWrapper + Page（多条件分页）                   │
│  └─ @Transactional（声明式事务）                               │
└──────────────────────────────┬───────────────────────────────┘
                               │ 调用
┌──────────────────────────────▼───────────────────────────────┐
│ 持久层 Mapper                                                  │
│  StudentMapper / ScoreMapper / ClassMapper / CourseMapper     │
│  AdminMapper（均继承 BaseMapper）                              │
└──────────────────────────────┬───────────────────────────────┘
                               │ JDBC
┌──────────────────────────────▼───────────────────────────────┐
│ MySQL 8：ssm_e2_mis                                           │
│  t_student / t_class / t_course / t_score / t_admin            │
└──────────────────────────────────────────────────────────────┘
```

## 2. Spring 父子容器

```text
Spring 根容器（SpringConfig）
├─ DruidDataSource
├─ MybatisSqlSessionFactoryBean
│   ├─ MybatisConfiguration（驼峰映射）
│   └─ MybatisPlusInterceptor（PaginationInnerInterceptor）
├─ MapperScannerConfigurer（com.jxy.mis.mapper）
├─ DataSourceTransactionManager
└─ Service 组件（com.jxy.mis.service）

SpringMVC 子容器（SpringMvcConfig）
├─ Controller（com.jxy.mis.controller）
├─ GlobalExceptionHandler（com.jxy.mis.common）
├─ WebLogAspect（com.jxy.mis.aspect）
├─ LoginInterceptor（登录拦截）
├─ RoleInterceptor（@RequireRole 角色权限校验）
├─ InternalResourceViewResolver（/WEB-INF/views/*.jsp）
└─ CORS / 静态资源放行
```

## 3. 请求链路

```text
浏览器
  → CharacterEncodingFilter
  → DispatcherServlet
  → LoginInterceptor（Session 校验）
  → RoleInterceptor（角色权限校验）
  → Controller（@Valid 校验）
  → WebLogAspect（记录入参/耗时）
  → Service（业务校验 + 事务 + LambdaQueryWrapper）
  → Mapper（BaseMapper / 条件构造器）
  → MySQL
  → 统一 Result{code,message,data,timestamp}
  → 浏览器 / ApiFox
```

## 4. 角色与权限

| 角色 | 权限范围 |
| --- | --- |
| ADMIN 系统管理员 | 全部功能：学生与成绩增删改查、批量删除、统计、事务验证 |
| TEACHER 教务老师 | 查看学生；录入/修改成绩；查看成绩统计；不能增删学生、不能删除成绩 |
| STUDENT 学生 | 只能查看自己的成绩与统计，不能访问学生管理页，不能修改任何数据 |

> 后端由 `RoleInterceptor` 读取 Controller 上的 `@RequireRole` 注解统一校验；学生账号通过 `t_admin.stu_id` 关联学生，成绩查询在 Service 层前强制过滤为本人。
